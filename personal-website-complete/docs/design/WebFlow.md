```
Buatkan pengembangan desain personal website berdasarkan Use Case berikut.
```

```
Aktor utama: Visitor / Pengunjung website
Aktor pendukung: Author sebagai pemilik konten website
```

```
Tujuan utama website:
Website ini digunakan sebagai personal website/portfolio milik author.
Pengunjung dapat melihat identitas visual author, showcase CSS, daftar project
pribadi, contact person, personal collection, dan blog pribadi. Desain harus
terasa modern, personal, kreatif, dan cocok untuk mahasiswa/creative developer.
```

```
Use Case Utama:
```

```
UC1 – Melihat Homepage dan Showcase CSS Author
Deskripsi:
Pengunjung membuka halaman utama website dan langsung melihat identitas author
serta showcase kemampuan CSS/visual design.
```

```
Sub Use Case:
UC1.1 – Melihat Showcase CSS Author
- Pengunjung melihat section utama yang menampilkan eksperimen CSS, animasi,
layout kreatif, atau visual style milik author.
- Showcase dapat berupa card, grid, preview interaktif, animasi hover, atau mini
component demo.
- Setiap showcase memiliki judul singkat, deskripsi pendek, dan visual preview.
```

```
UC1.2 – Navigasi ke Tiap Halaman
```

```
- Pengunjung dapat berpindah ke halaman Contact, Projects, Collection, dan Blog.
```

```
- Navigasi tersedia melalui navbar utama.
```

```
- Navbar harus jelas, responsif, dan tetap mudah digunakan di desktop maupun
mobile.
```

- `Tambahkan active state untuk menunjukkan halaman yang sedang dibuka.`

```
UC2 – Melihat Contact Person Author
Deskripsi:
Pengunjung dapat melihat informasi kontak author untuk kebutuhan komunikasi,
kolaborasi, atau networking.
```

```
Konten yang perlu ada:
```

- `Email`

```
- Instagram / LinkedIn / GitHub
```

```
- Tombol direct contact
```

- `Lokasi umum atau status availability, jika relevan`

- `Form kontak opsional dengan field nama, email, pesan`

```
Arah desain:
```

```
Buat halaman/section contact yang ringkas, mudah dipindai, dan punya CTA yang
jelas seperti “Contact Me”, “Send Message”, atau “Let’s Connect”.
```

```
UC3 – Melihat Projects Pribadi Author
Deskripsi:
Pengunjung dapat melihat daftar project pribadi yang pernah dibuat author.
```

```
Konten yang perlu ada:
```

```
- Nama project
```

- `Deskripsi singkat`

- `Tech stack`

- `Screenshot/preview project`

- `Link demo/live site`

- `Link GitHub/source code`

- `Status project, misalnya Finished, In Progress, atau Experimental`

```
Arah desain:
```

```
Gunakan layout project cards atau project grid. Setiap project harus terasa
```

```
seperti portfolio item yang bisa dipahami cepat oleh recruiter, teman, atau
dosen.
```

```
UC4 – Melihat Personal Collection Author
```

```
Deskripsi:
```

```
Pengunjung dapat melihat koleksi pribadi author. Collection bisa berupa hal-hal
yang author suka, referensi desain, playlist, buku, game, anime, foto, tools,
atau resource favorit.
```

```
Konten yang perlu ada:
```

- `Kategori collection`

- `Item collection dengan gambar/icon`

- `Judul item`

- `Deskripsi pendek`

- `Tag/kategori`

# `Arah desain:`

```
Buat collection terasa lebih personal dan ekspresif dibanding halaman project.
Bisa menggunakan masonry grid, gallery, atau card collection dengan visual yang
kuat.
```

```
UC5 – Melihat Personal Blog Author
```

```
Deskripsi:
Pengunjung dapat membaca tulisan pribadi author, seperti catatan belajar,
pengalaman project, opini teknologi, refleksi kuliah, atau dokumentasi proses
kreatif.
```

```
Konten yang perlu ada:
```

- `Daftar artikel blog`

- `Judul artikel`

- `Tanggal publish`

- `Kategori/tag`

- `Ringkasan singkat`

- `Halaman detail artikel`

- `Search/filter blog opsional`

# `Arah desain:`

```
Blog harus nyaman dibaca. Gunakan typography yang jelas, spacing lega, dan
layout artikel yang bersih.
```

```
Struktur Halaman yang Disarankan:
```

`1. Home / Showcase CSS`

`2. Contact`

`3. Projects`

`4. Collection`

`5. Blog`

```
Gaya Desain:
```

- `Modern personal portfolio`

- `Kreatif tapi tetap rapi`

- `Responsif untuk desktop dan mobile`

- `Gunakan visual hierarchy yang jelas`

- `Navbar mudah diakses`

- `Section tidak terlalu ramai`

```
- Berikan sentuhan animasi halus pada hover, transition, dan page movement
- Cocok untuk personal branding seorang mahasiswa Informatics/creative web
developer
```

# `Output desain yang diharapkan:`

```
Kembangkan layout, komponen UI, visual hierarchy, dan alur navigasi berdasarkan
use case di atas. Pertahankan desain awal yang sudah ada, tetapi perbaiki
konsistensi, spacing, responsiveness, dan pengalaman pengguna.
```
